# 浙考申论智阅

浙江省考申论 AI 批改智能体。不只给分，还要说明分数怎么来的、最该改哪里，以及修改后是否真的学会了。

> 模拟评分，仅供训练参考，不等同于正式考试分数。题库收录浙江省考 A/B/C 卷历年真题（附来源），不含机构参考答案；评分点由模型按材料生成。

## 功能

- **真题题库**：浙江省考 A 卷（综合类）、B 卷（基层类）、C 卷（行政执法类）2023—2026 年度共 12 套，材料与题目并排。
- **AI 出题**：选卷别和主题，按同卷别最近一年真题的题型、分值、字数结构生成一套模拟卷，生成后直接作答批改。
- **导入真题**：在粉笔等网站复制整套卷粘贴进来，按规则原样切分成材料和题目（不经模型改写），预览修正后写入 `backend/app/data/papers/` 并入库。
- **申论助手**：对话智能体，查真题和材料（「哪套卷讲过千万工程」）、问题型方法、分析自己的批改记录。只读，回答注明出处。
- **整卷作答**：整卷或部分题。在线作答时左边是给定资料、右边逐题作答，草稿自动保存。
- **资料标记**：作答时在给定资料上用三色荧光笔、下划线标记，可擦除、撤销，自动保存到答卷。
- **导出 PDF**：试卷排成 A4 版式（卷头、注意事项、资料、作答要求），可带上自己的标记、附方格答题纸，用浏览器「另存为 PDF」导出。
- **拍照上传与质量检测**：JPG / PNG / PDF 多页上传。本地检测模糊、反光、阴影、倾斜、重复页、分辨率，按 A—D 分级并定位到页面区域。D 级禁止识别，C 级需确认风险。
- **识别与分题**：视觉模型逐行识别并按答题卡题号切分，低把握行标黄，原图与文本并排逐行核对、改题号；不选卷直接上传时按答案用词匹配是哪套卷。
- **证据化批改**：评分账本逐点给出「材料依据 → 你的原文 → 判断」。要点型维度按评分点累加，等级型维度（大作文、格式、语言）按档次打分。
- **红线批注**：五色分级，默认只展开影响最大的 5 条。
- **分数区间与置信度**：置信度由题目匹配、识别质量、证据通过率、复核一致性相乘得出，公式在报告里可展开查看。
- **反事实增分**：按「预计增分 ÷ 耗时」排出先改哪里。
- **分层提示**：问题 → 提示 → 局部示范 → 参考答案，服务端逐级解锁。
- **二次修改与版本对比**：得分变化、新增/丢失得分点、修复/新增问题、逐句 diff。
- **学习画像**：错误模式库、能力维度、训练处方（带通过标准和换主题复测题），能识别「原题修复但迁移失败」。
- **申诉与教师复核**：学员对评分点申诉，系统先自动重检再进教师队列；低置信度批改自动入队。教师改判保留 AI 原判，用于后续校准。

## 批改智能体

LangGraph 固定顺序状态图，对应 PRD 第 16 章的多智能体职责：

```text
题目理解 → 材料证据 → 评分 → 证据校验 ─┬─(有疑点)→ 复核裁决 → 教练
                                       └──────────────────→ 教练
```

- **证据校验**是关键一环：模型声称命中的评分点，引用必须逐字出现在答案里。找不到的送大模型复核，复核后仍找不到按未命中处理。无依据的批注直接丢弃。
- 只对有疑点的评分点复核，不整题重跑，控制成本与耗时。
- 分数由确定性代码核算，模型只负责判断命中状态，同一组判断永远得到同一个分数。
- 考生答案作为不可信输入包在 `<answer>` 标签里，提示词明确它不是指令。

未配置模型时，全部功能仍可使用：识别改为手动录入，批改由**规则引擎**完成（关键词分句匹配、空泛对策、摘抄、重复、口语化、格式要素检测）。报告会标注「规则评分」，置信度最高到「中」，大作文封顶 0.4。

## 快速开始（Windows）

需要 Python 3.11+ 和 Node.js 18+。

1. 双击 `install.bat`
2. 双击 `scripts\start.bat`，服务就绪后自动打开 http://127.0.0.1:8100（端口可在 `backend\.env` 的 `APP_PORT` 修改；被占用时会报错退出，不会打开别的程序的页面）
3. 首次启动会在窗口里打印 `student`、`teacher` 两个演示账号的**随机密码**，只显示一次

启用模型：编辑 `backend\.env`（安装时从 `.env.example` 复制），填写 `LLM_BASE_URL`、`LLM_API_KEY` 和模型名，重启。任何 OpenAI 兼容接口都可以，拍照识别需要支持图片输入的模型。

### 手动安装 / 其他系统

```bash
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt   # Windows: .venv\Scripts\pip
cd frontend && npm install && npm run build && cd ..
cp backend/.env.example backend/.env
cd backend && ../.venv/bin/python main.py
```

开发时前端可单独 `npm run dev`（5174 端口，代理到后端 8100）。

## 测试

```bash
cd backend && ../.venv/bin/python -m pytest
```

覆盖规则引擎、分数与置信度核算、LangGraph 流程（用假模型模拟编造引用）、图像质量检测、接口端到端流程与权限隔离。

## 安全与隐私

- 只认 `Authorization: Bearer` 令牌，没有请求头旁路。开放注册只能注册学员，教师账号由已有教师创建。
- 学员只能访问自己的作答；教师只能看进入复核队列的作答，队列里学员身份脱敏。
- 首次拍照上传前必须知情同意（说明图片发给哪个模型服务），不同意只能手动录入。图片发送前缩小并去掉 EXIF。
- 答案文本在确认时脱敏手机号、身份证号、准考证号、邮箱。原图可一键删除，只经鉴权接口访问。
- 上传按文件头校验类型，文件名随机生成。模型密钥只在服务端 `.env`，接口不读写。

**部署到公网前**请注意：本项目按单机 / 内网使用设计，没有登录限流和 HTTPS，需要在前面加反向代理；并把 `SEED_DEMO_ACCOUNTS` 设为 `false`。
