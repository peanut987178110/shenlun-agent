## 二、补充的定义

**字数**：去除空白后的字符数，含标点。与申论方格纸的占格规则一致。

**置信度**（0—1）：

```text
置信度 = 题目匹配系数 × 识别质量系数 × 证据通过率 × 复核一致系数
```

| 因子 | 取值 |
|---|---|
| 题目匹配系数 | 精确匹配 1.0；相似匹配 0.85；仅题型规则 0.6。评分配置由模型生成、未经教研确认的，最高 0.85 |
| 识别质量系数 | 手动录入或 PDF 文字层 1.0；OCR 按低置信行占比从 1.0 线性降到 0.7 |
| 证据通过率 | 模型声称「命中」且引用原文确实出现在答案中的评分点占比；规则引擎固定 0.75（保证规则评分最高只到「中」） |
| 复核一致系数 | 未触发复核 1.0；第二模型与初评一致 1.0，不一致 0.8 |

≥0.8 为高，0.6—0.8 为中，<0.6 为低。低置信度自动进入教师复核队列。

**分数区间**：`半宽 = 满分 × (1 − 置信度) × 0.3`，至少 0.5 分，区间裁剪到 [0, 满分]。

## 三、MVP 范围（本仓库实现）

实现：

- 账号（学员 / 教师），目标设置
- 真题题库：浙江省考 A/B/C 卷历年题干与给定资料，按年度、卷别浏览，作答时材料与题目并排显示
- 评分配置：真题与模拟卷首次批改时由模型按材料生成并落库，之后同题共用，分数前后可比
- 答卷流程：整卷或部分题，上传后按题号切分，逐行确认，各题分别批改
- 申论助手、AI 出题（见修订 #15）
- 上传：JPG / PNG / PDF，多页；本地图像质量检测（清晰度、反光、阴影、倾斜、重复、分辨率），A—D 分级
- 识别：视觉模型 OCR；PDF 文字层直接提取；未配置模型时手动录入
- 识别结果确认与编辑，低置信行标黄
- 题目匹配：精确 / 相似 / 仅题型规则，三级，用户确认后才批改
- 批改：LangGraph 编排（题目理解 → 材料证据 → 评分 → 证据校验 → 按需复核 → 教练），未配置模型时走规则引擎并明确标注
- 评分账本、红线批注（默认只展开前 5 条）、分数区间与置信度
- 反事实增分建议、分层修改提示（问题 → 提示 → 局部示范 → 参考答案，逐级解锁）
- 二次修改、复评、版本对比
- 错误模式库、能力画像、训练处方（含通过标准和复测题）
- 评分申诉、教师复核队列

不实现（列为后续）：全卷限时模拟与考场能力分析、自动生成迁移题（MVP 从题库挑同题型不同主题的题作为复测题）、会员与付费、移动端与小程序、断点续传、班级与机构管理、评测集。

## 四、上线前置条件（代码之外）

- **评测集**：PRD §19.2 的准确率目标（OCR ≥95%、得分点召回 ≥85% 等）没有标注数据就无法验收。上线前需要一批由教师评过分的真实答卷，建议不少于 200 份，覆盖五种题型。
- **教研评分配置**：真题与模拟卷的评分点由模型生成，正式使用前应由浙江省考教研人员抽查确认。
- **真题核对**：题库真题从公开网页收集，已做双来源交叉核对，但网上流传的「真题」有回忆版和错漏，发现问题可直接改 `backend/app/data/papers/*.json`。
- **模型服务合规**：确认所选视觉 / 语言模型服务的数据使用条款，写进知情同意文案。
