# 浙江省考申论 AI 智能批改智能体需求分析文档

## 一、项目概述

### 1.1 项目名称

浙江省考申论 AI 智能批改智能体。

### 1.2 产品定位

面向浙江省公务员考试申论备考用户，提供从答卷上传、文字识别、题目匹配、智能批改、红线标注、评分解释，到二次修改和个性化训练的完整服务。

产品不只是“AI 打分工具”，而是：

> 基于证据链评分、失分机制诊断和能力迁移验证的浙江省考申论智能教练。

### 1.3 产品核心价值

用户完成一次答题后，系统需要帮助用户明确：

- 这道题预计得多少分；
- 为什么是这个分数；
- 哪些内容命中了得分点；
- 哪些内容没有得分；
- 最应该先修改哪里；
- 修改后预计能够提升多少；
- 下次遇到类似题目应该如何作答；
- 用户是否真正掌握了对应能力。

# 二、项目背景

## 2.1 用户背景

申论备考具有以下特点：

- 主观题占比高；
- 评分标准复杂；
- 同一题存在多种合理表达；
- 题型之间的作答逻辑差异较大；
- 人工批改成本高；
- 用户很难获得高频、及时、持续的反馈；
- 用户经常知道“错了”，但不知道“为什么反复错”。

传统学习方式主要依赖：

- 参考答案；
- 课程讲解；
- 线下人工批改；
- 题库刷题；
- 统一模板。

这些方式存在反馈慢、个性化程度低、难以跟踪长期能力变化等问题。

## 2.2 市场背景

当前市场上的申论产品已经逐步具备：

- 历年真题库；
- 题目解析；
- 拍照上传；
- 手写 OCR；
- AI 评分；
- 红线批注；
- 作文点评；
- 错题本；
- 学习计划；
- AI 对话；
- 人工批改服务。

因此，单纯具备“拍照上传、自动批改、评分和红线标注”已经不足以形成明显竞争力。

本产品需要进一步解决：

1. AI 评分是否可信；
2. 扣分依据是否透明；
3. 用户能否理解反馈；
4. 用户能否根据反馈完成修改；
5. 修改后是否真的提高；
6. 能否将能力迁移到陌生题；
7. 是否适配浙江省考的年份、类别和评分规则。

# 三、问题定义

## 3.1 用户问题

### 问题一：人工批改成本高

用户无法高频获得有质量的人工反馈，导致大量答案“写完即结束”。

### 问题二：AI 批改结果不透明

很多产品直接给出分数或评价，但用户看不到：

- 对应的材料依据；
- 具体得分点；
- 评分规则；
- 扣分幅度；
- 同义表达是否被认可。

### 问题三：反馈过于笼统

例如：

- 逻辑不清；
- 对策不具体；
- 论证不充分；
- 语言需要优化。

这些反馈无法直接转化为修改行为。

### 问题四：用户反复犯同样的错

传统错题本只能记录“哪道题错了”，不能记录：

- 错误是什么；
- 为什么会出现；
- 在什么情况下出现；
- 过去出现了多少次；
- 是否已经改正。

### 问题五：参考答案依赖严重

用户看完高分答案后，可能产生“我已经会了”的错觉，但在新题中仍无法独立完成。

### 问题六：浙江省考适配不足

不同年份、考试类别和试卷类型可能存在题型、分值、字数和评价重点差异，通用申论评分规则不一定适合所有浙江省考场景。

### 问题七：平时训练与真实考场脱节

用户平时可以慢慢写，但考试时可能出现：

- 时间不够；
- 最后一题写不完；
- 后半程字迹变差；
- 修改次数过多；
- 题目之间时间分配不合理。

# 四、产品目标

## 4.1 用户目标

- 降低申论批改成本；
- 提高反馈速度；
- 理解得分点与扣分点；
- 找到重复出现的失分机制；
- 获得明确的修改路径；
- 通过二次修改验证反馈效果；
- 通过陌生题验证能力迁移；
- 提升真实考场下的稳定得分能力。

## 4.2 产品目标

第一阶段完成以下闭环：

```text
拍照上传
→ 图像质量检测
→ OCR 识别
→ 题目匹配
→ 题型识别
→ 评分标准匹配
→ AI 批改
→ 证据链解释
→ 红线标注
→ 二次修改
→ 复评
→ 能力画像
→ 个性化训练
```

## 4.3 商业目标

- 面向个人用户提供会员服务；
- 面向教师提供 AI 初批和复核工具；
- 面向机构提供批量批改和教学数据服务；
- 通过教师修正数据、争议答案和用户版本数据形成模型壁垒；
- 以浙江省考为切入口，后续扩展到其他地区和考试类型。

# 六、目标用户分析

## 6.1 基础备考者

### 特征

- 不熟悉申论题型；
- 不理解得分点；
- 容易摘抄材料；
- 不会判断内容是否具体；
- 对评分规则缺乏认知。

### 需求

- 题型讲解；
- 术语解释；
- 逐句反馈；
- 典型答案对比；
- 分层提示；
- 修改示范。

## 6.2 中等水平考生

### 特征

- 已完成一定数量练习；
- 能够基本完成答题；
- 分数长期不稳定；
- 同类问题反复出现；
- 不知道下一步该练什么。

### 需求

- 失分因果诊断；
- 错误频率统计；
- 专项训练处方；
- 旧题复做；
- 迁移测试；
- 分数提升验证。

## 6.3 冲刺考生

### 特征

- 考试时间紧；
- 有明确目标分数；
- 关注限时、整卷和考场表现；
- 不愿意阅读过长报告。

### 需求

- 快速批改；
- 重点问题排序；
- 修改增分预测；
- 时间分配分析；
- 全真模拟；
- 高压场景训练。

## 6.4 教师用户

### 特征

- 批改量大；
- 需要统一评分尺度；
- 需要掌握学生共性问题；
- 不希望花大量时间处理 OCR 和基础标注。

### 需求

- AI 初批；
- 低置信度筛选；
- 教师复核；
- 自定义评分点；
- 班级统计；
- 学生报告。

## 6.5 机构用户

### 需求

- 批量批改；
- 班级管理；
- 教学数据；
- 私有题库；
- 私有评分规则；
- API 或私有化部署。

# 七、产品定位与竞争策略

## 7.1 不应作为核心卖点的功能

以下功能属于市场基础能力：

- 拍照上传；
- OCR；
- 自动评分；
- 红线标注；
- 题库；
- 错题本；
- AI 对话；
- 学习计划。

## 7.2 核心差异化方向

### 1. 评分账本

每一个核心得分点都显示：

```text
材料证据
→ 用户答案
→ 得分点
→ 命中状态
→ 评分结论
```

### 2. 失分因果诊断

例如：

```text
对策空泛
→ 未识别执行主体
→ 只提取了“做什么”
→ 没有提取“谁做、怎么做”
→ 对策缺少可操作性
```

### 3. 反事实增分

系统告诉用户：

- 先改哪里；
- 修改成本多大；
- 预计增分多少；
- 哪种方案性价比最高。

### 4. 答案版本控制

系统保存：

- 原始答案；
- 用户自改版；
- AI 指导版；
- 限时重写版；
- 隔周迁移版。

### 5. 迁移能力验证

不只判断原题是否修改正确，还通过换材料、换题型和换主题验证用户是否掌握方法。

### 6. 争议评分复核

允许用户质疑 AI 的评分，并经过：

- 原图复查；
- OCR 复核；
- 材料重检；
- 同义表达判断；
- 第二模型复核；
- 教师复核。

# 十、浙江省考专项需求

## 10.1 配置化要求

系统需要对以下内容进行版本化管理：

- 考试年份；
- 试卷批次；
- 考试类别；
- 题型；
- 题目分值；
- 作答字数；
- 应用文格式；
- 评分维度；
- 得分点；
- 同义表达；
- 评分权重；
- 参考答案；
- 教研备注；
- 评分标准来源和更新时间。

## 10.2 题目匹配规则

### 精确匹配

根据：

- 试卷名称；
- 年份；
- 类别；
- 题号；
- 题干；
- 材料文本。

### 相似匹配

通过题干、材料和关键词相似度匹配。

### 通用规则匹配

在没有找到历史题目的情况下，根据用户上传的题干和题型规则批改。

系统必须明确提示：

> 当前未匹配到本题的教研评分配置，本次结果采用通用题型评分规则，评分置信度较低。

【修订】原文为「未匹配到完整官方评分细则」。浙江省考不公开阅卷细则，系统中不存在「官方细则」，这样写会让用户误以为匹配成功时用的是官方标准。统一称「教研评分配置」，并标注来源与更新时间。

## 10.3 浙江本地化资料库

应建立：

【修订】题库收录浙江省考 A/B/C 卷历年真题（题干与给定资料，附来源），不收录机构参考答案；评分点由模型按材料生成并标注。见需求修订说明 #3。

- 浙江省考历年试卷库；
- 题目级评分点库；
- 材料段落级标签库；
- 浙江省考常见主题库；
- 浙江省考高频表达库；
- 不同分数段答案库；
- 评分争议样本库；
- 教师复核数据集。

# 十一、分题型需求

## 11.1 归纳概括题

### 评分重点

- 要点是否齐全；
- 是否概括准确；
- 是否合并同类信息；
- 是否保留核心逻辑；
- 是否存在案例复述；
- 是否出现主观延伸；
- 是否符合字数要求。

### 核心输出

- 得分点矩阵；
- 完整命中、部分命中和未命中；
- 材料位置；
- 多余内容；
- 推荐压缩表达；
- 最小修改建议。

## 11.2 综合分析题

### 评分重点

- 是否准确理解题干观点；
- 是否结合材料；
- 是否完成原因和影响分析；
- 是否回应核心问题；
- 是否存在逻辑跳跃；
- 是否机械套用模板。

### 核心输出

- 观点理解判断；
- 材料证据；
- 分析链条；
- 缺失环节；
- 结构调整建议。

## 11.3 提出对策题

### 评分重点

- 问题识别；
- 对策对应；
- 执行主体；
- 行动措施；
- 执行方式；
- 保障机制；
- 可操作性；
- 字数控制。

### 对策结构

```text
责任主体 + 目标对象 + 具体行动 + 执行方式 + 保障机制
```

示例：

原文：

> 加强宣传，提高群众认识。

问题：

- 宣传对象不明确；
- 执行主体缺失；
- 宣传方式不明确；
- 未体现要解决的具体问题。

## 11.4 应用文

### 评分重点

- 文种；
- 标题；
- 称谓；
- 身份；
- 对象；
- 语气；
- 写作目的；
- 正文内容；
- 结尾；
- 落款；
- 日期；
- 字数。

系统必须根据具体文种动态判断格式，不得机械套用统一模板。

## 11.5 大作文

### 评分重点

- 是否扣题；
- 立意是否准确；
- 中心论点是否明确；
- 分论点是否重复；
- 结构是否完整；
- 材料是否有效转化；
- 论据是否支持观点；
- 是否存在空泛论证；
- 语言是否规范；
- 是否满足字数要求。

### 输出内容

- 预计分数区间；
- 立意判断；
- 中心论点；
- 分论点关系；
- 论据有效性；
- 最薄弱段落；
- 最小修改方案；
- 可选重写路径。

# 十二、评分系统需求

## 12.1 评分输出

```text
预计得分：64 分
合理区间：61—67 分
评分置信度：78%
```

## 12.2 评分依据

每个评分结论必须尽量包含：

- 题目要求；
- 材料证据；
- 用户原文；
- 评分点；
- 判断理由；
- 分数影响；
- 修改建议。

## 12.3 得分状态

- 完整命中；
- 部分命中；
- 表达争议；
- 未命中；
- 材料外推；
- 与其他要点重复。

## 12.4 多模型裁决

当不同模型结论不一致时：

1. 重新检索材料；
2. 检查同义表达；
3. 调用第二评分模型；
4. 生成分数区间；
5. 降低置信度；
6. 必要时提交人工复核。

# 二十一、主要风险与应对方案

| 风险 | 影响 | 应对方案 |
|---|---|---|
| AI 评分不稳定 | 用户错误训练 | 多模型评分、评分区间、置信度和人工复核 |
| 同义表达误判 | 合理答案被扣分 | 建立同义表达库和争议样本库 |
| OCR 错误 | 批改结论失真 | 识别确认、低置信度提醒、原图回看 |
| 参考答案依赖 | 用户不会独立作答 | 分层提示、延迟答案、迁移测试 |
| 浙江省考规则变化 | 评分失效 | 评分标准版本化维护 |
| 报告过于复杂 | 用户不愿阅读 | 首屏只展示三个关键问题，支持分层报告 |
| 隐私泄露 | 合规与信任风险 | 脱敏、加密、删除、授权管理 |
| 产品承诺过高 | 用户产生误解 | 明确仅为训练参考，不等同正式考试分数 |

# 二十二、需求分析结论

浙江省考申论 AI 智能批改智能体的核心价值，不是单纯提高批改速度，而是建立从“答案”到“能力提升”的完整链路。

产品必须同时具备五种能力：

1. 识别能力：准确识别题目、材料和手写答卷。
2. 评分能力：根据浙江省考配置进行分题型批改。
3. 解释能力：让每个评分结论都有证据和理由。
4. 干预能力：告诉用户下一步如何修改和训练。
5. 验证能力：判断用户是否将方法迁移到陌生题。

产品最具竞争力的创新方向包括：

- 评分账本；
- 材料—答案—得分点证据链；
- 失分因果诊断；
- 反事实增分；
- 答案版本管理；
- 评分争议复核；
- 错误模式库；
- 个性化训练处方；
- 跨题迁移测试；
- 浙江省考评分标准版本化；
- 教师校准数据体系；
- 考场能力数字画像。

最终产品定位应为：

> 浙江省考申论的证据化评分、失分诊断与能力增分智能体。

核心产品承诺可以概括为：

> 不只告诉你得了多少分，还告诉你分数是怎么来的、最应该改什么，以及你是否真的学会了。
