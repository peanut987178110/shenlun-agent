## 1 背景

申论是主观题考试，备考有四个难点：

1. **反馈贵且慢**：人工精批一次要付费、要等，大多数答案写完就结束了。
2. **反馈不透明**：拿到一个分数或一句「对策空泛」，不知道对应哪条材料、哪个得分点。
3. **同样的错反复犯**：错题本只记「哪题错了」，不记「为什么错、在什么情况下错」。
4. **看答案的错觉**：看完高分答案觉得会了，换一套材料照样写不出来。

市面产品已普遍具备拍照上传、AI 打分、红线批注、错题本。这些是基础能力，不构成差异。本产品要解决的是：**分数可信吗？扣分依据透明吗？考生能据此改吗？改完是真学会了吗？**

## 2 浙江省考申论的特点

浙江省考分级分类考试，申论分三类卷（[华图整理的公告考试类别](https://www.huatu.com/2023/0831/2682260.html)）：

| 卷别 | 适用 | 对产品的影响 |
|---|---|---|
| A 综合类 | 县级以上机关 | 题库、出题、筛选都按「年度 + 卷别」组织 |
| B 基层类 | 乡镇（街道） | 同上 |
| C 行政执法类 | 一线执法职位 | 同上 |
| D 村干部类 | 面向村干部 | 考《综合应用能力》，**不考申论**，题库不收 |

题库 2023—2026 年度 11 套真题的共同结构：**三道题，20 / 30 / 50 分，150 分钟**。

| | 第 1 题（20 分） | 第 2 题（30 分） | 第 3 题（50 分） |
|---|---|---|---|
| 题型 | 应用文 5 套、归纳概括 5 套、提出对策 1 套 | 应用文（多为短评）10 套、综合分析 1 套 | 大作文 11 套 |
| 字数 | ≤300 | ≤500—600 | 1000—1200 |

由此得出的需求：

- **应用文和大作文占 80 分**，评分不能只靠「要点命中」，必须有按档次打分的等级型维度（格式、身份语气、立意、论证、语言）。
- **大作文 50 分**，评分维度满分必须随题目分值缩放。
- AI 出题要照搬这个结构，不能凭印象出五道题。
- 真题大作文多写「结合给定资料」，不指定资料编号，批改时要把全部资料作为依据。

## 3 用户分析

| 用户 | 现状 | 核心需求 | 对应功能 |
|---|---|---|---|
| 基础备考者 | 不懂得分点，爱摘抄 | 知道每一分怎么来的；有人一步步带着改 | 评分账本、分层提示、摘抄检测 |
| 中等水平考生 | 分数卡在中段，同类错误反复 | 找到反复出现的失分机制；有目标的练习 | 错误模式库、训练处方、换题复测 |
| 冲刺考生 | 时间紧，练整卷 | 快速批改；只看最该改的 | 整卷并行批改、「先改哪里最划算」 |
| 纸笔练习者 | 习惯在纸上写、在资料上划 | 打印试卷；在线也能划资料；拍照批改 | 导出 PDF（带方格纸）、资料标记、拍照上传与分题 |
| 教师 | 批改量大 | 只处理有争议、低置信度的 | 复核队列、逐点改判 |

## 5 关键需求分析与设计取舍

### 5.1 「可信的分数」怎么落地

考生不信任 AI 分数，根源不是分数高低，而是**无法验证**。所以：

- **每一分都能追溯**：评分账本逐点列出「材料依据 → 考生原文 → 判断」。
- **引用必须是真的**：模型说命中了，必须逐字引用答案原文。系统逐条核对，找不到的送大模型复核，复核后仍找不到就不给分。宁可少给，不给无依据的分。
- **判断与算分分开**：模型只判断每个评分点是命中、部分命中还是未命中；分数由确定性代码核算。同一组判断永远得到同一个分数。
- **承认不确定**：给区间和置信度，而不是一个精确到 0.5 的数字；低置信度自动转教师。

取舍：V1.0 设想「多模型交叉评分」。每题都跑多个模型会让成本翻倍、耗时翻倍，所以改为「单模型 + 证据校验 + 只对疑点复核」。

### 5.2 没有阅卷细则怎么批

浙江省考不公开阅卷细则，机构参考答案互相不一致，也不是官方标准。选择：

- 第一次批改某道题时，由大模型**只依据材料**生成评分点（带材料出处与关键词），落库固定。之后这道题的每次批改、每次复评都用同一份，分数前后可比。
- 明确标注「AI 生成，待教研确认」，置信度里的匹配系数最高按 0.85 计。
- 教师改判保留 AI 原判，积累起来就是替换、校准评分点的依据。

### 5.3 为什么以「答卷」为单位

V1.0 流程是「上传一张图 → 匹配一道题」。实际答题卡一页往往写着两三道题，一道大作文又跨好几页，逐题上传行不通。改为：

- 整份答卷一起上传、一起识别；视觉模型根据答题卡印刷的题号区域标出每行属于第几题。
- 考生答案内部自己写的「一、二、三」是分条序号，不是题号，切分规则要能区分。
- 切分结果**一定交给用户逐行确认**，不直接拿去批改。
- 不选卷就上传时，申论答案大量复用材料用词，所以「答案里的词有多少出现在这套卷的材料里」比题干相似度更能认出是哪套卷。

### 5.4 默认不给参考答案

「看答案的错觉」是申论备考的核心问题。四级提示逐级解锁，并且在**服务端**控制：前端拿不到还没解锁的内容，而不是只在界面上藏起来。看过局部示范后提交的修改记为「AI 指导版」，与自改版区分，画像里能看出区别。

### 5.5 真题怎么进题库

- 题库里的 11 套真题从公开网页逐字收集，每套至少两个独立来源交叉核对，附来源链接。
- 粉笔等题库网站需要登录，且本项目的运行环境访问不到，所以系统**不自动抓取**，而是提供「导入真题」：考生在自己浏览器里复制整卷，粘贴后按规则切分。
- 切分全程不经过模型：模型改写一个字，材料依据就失真了。

### 5.6 AI 出题要「像浙江卷」

「像」指结构一致，不是凭印象：题型、分值、字数照搬同卷别最近一年的真题。

实现中遇到的问题与处理：

- 一次调用写全部材料时，模型会把篇幅压到要求的一半以下（实测 4 则约 1900 字）。改为先设计方案，再逐则并行撰写，不足 70% 自动重写。
- 材料里人物原话常带引号，模型写成英文双引号会破坏结构化输出，导致生成失败。材料正文改用纯文本输出。
- 材料用虚构地名人物，不编造真实数据和政策文号，界面标注「虚构情境」。

## 6 约束与假设

| 类型 | 内容 |
|---|---|
| 模型 | 依赖 OpenAI 兼容网关。未配置时：在线录入可用，规则引擎只能批带关键词评分点的题；真题首次批改、拍照识别、AI 出题、申论助手不可用 |
| 网络 | 运行环境的企业防火墙拦截部分教育网站（包括粉笔），真题补充走人工导入 |
| 部署 | 单机 / 内网；SQLite；没有登录限流和 HTTPS |
| 评分 | 所有分数是模拟评分；评分点由 AI 生成，未经教研确认 |
| 隐私 | 答卷图片在发送前无法本地脱敏，依赖知情同意与「拍照避开姓名栏」 |

## 7 验收标准

| 范围 | 标准 | 验证方式 |
|---|---|---|
| 题库 | 真题 JSON 全部通过格式校验；各题分值之和 100 | 自动化测试 |
| 导入 | 11 套真题还原为 3 种排版后切分，材料与题干逐字一致 | 自动化测试 |
| 答卷 | 题号行、草稿行不进答案；分条序号不被当成题号；他人答卷 404 | 自动化测试 |
| 批改 | 编造的引用经复核后判为未命中；无依据批注被丢弃；等级分不超上限；大作文满分 50 | 自动化测试 |
| 提示 | 不能跳级解锁；未解锁内容不下发 | 自动化测试 |
| 标记 | 拖选标记、跨段、刷新保留、橡皮擦 | 浏览器实测 |
| 导出 | 带标记与方格纸导出 A4 PDF | 浏览器实测 |
| 出题 | A / B / C 三套并发生成成功，结构与模板一致，可批改 | 真实网关实测 |
| 整体 | 注册 → 出题 → 整卷作答 → 批改 → 报告 → 真题作答 → 导入 → 助手，全程无报错 | 真实网关浏览器实测 |

当前：81 个后端自动化测试通过；上表实测项均已完成。
